This checkpoint carries the real PC2004 Sonic pipeline from the validated host renderer into a native Nintendo 3DS **Citro3D/PICA200 source runtime**.

## Status

**PASS — source/build gate. Hardware verification pending.**

This environment does not contain devkitARM, so this checkpoint does **not** claim that a `.3dsx` was compiled or executed here. The user has devkitARM and can build the included runtime locally from the supplied source.

## Controls

- L/R: previous/next animation
- A: pause animation
- B: reset animation frame
- X: cycle culling none/back/front
- Y: toggle debug V inversion
- D-pad left/right: rotate Sonic
- D-pad up/down: zoom
- START: exit
