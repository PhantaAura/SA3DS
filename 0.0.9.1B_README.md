# SA3DS 0.0.9.1B — Emerald Coast Visual / Material / PVM Decode

This checkpoint moves the Emerald Coast importer from collision-only geometry
to renderable source-neutral stage data.

## Added

- strict generic PC2004 PVM/PVRT parser for the currently proven SA1 encodings;
- exact Emerald Coast `BEACH01/02/03.PVM` decode;
- validation coverage for `OBJ_BEACH.PVM`, `BEACH_SEA.PVM`, `BG_BEACH.PVM`;
- pointer-free `SA3DVIS` geometry with position, normals and signed-16/255 UVs;
- pointer-free `SA3DMATL` material records;
- per-act `.sa3dspak` owner-side builder with GEOMETRY/MATERIALS/TEXTURES;
- exact material->PVM texture-index range validation;
- base-first format-9 PVRT correction, including the legacy SONIC.PVM decoder;
- exact-source regression tests and visual evidence report.

## Not yet decoded

- SET object semantics/runtime spawning;
- CAM record semantics/runtime camera controller;
- reusable object model/resource registry (`OBJ_BEACH` is texture-validated but
  not yet associated with object models);
- dynamic collision producer/consumer semantics;
- full stage event/script semantics;
- final Old-3DS PICA texture residency/transcoding strategy.

`PHYSICS_1TO1 = false` remains unchanged.  0.0.9.0G still awaits real Old 3DS
hardware validation because the user's charger is unavailable.

Next milestone: **0.0.9.1C — SET Decode + Object Placement Registry**.
