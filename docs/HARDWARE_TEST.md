# Old 3DS hardware test checklist

This build is a movement-lab checkpoint, not a Sonic Adventure parity claim.

1. **Deadzone/drift** — with hands off the Circle Pad, the actor should remain still.
2. **Acceleration** — full forward should ramp smoothly rather than instantly snap to speed.
3. **Braking** — at speed, hold reverse. The actor should brake before reversing.
4. **Steering** — low speed should turn more sharply than high speed.
5. **Jump** — compare tap B vs held B; held B should produce the higher jump.
6. **Slope** — uphill should resist speed and downhill should assist it.
7. **Bank** — cross-bank surface should not violently snap or hover.
8. **Camera** — Y recenters; normal steering should move the chase direction gently.
9. **Reset** — deliberately leave the course; falling should reset to the start.
10. **Frame feel** — note hitching, input delay, or any direction where the Circle Pad feels weaker.

SELECT enables the developer overlay. Normal top-screen presentation stays clean.
