# SA3DS 0.0.9.1E-WIP6 — Sonic Geometry GPU Submission Preflight

Parent: **0.0.9.1E-WIP5**, SHA-256 `1fe804ad91ad714b3641ef4d739da899ea1a301b1b9b54817768a30388c15657` (independently verified by sha256sum and unzip -t on Oct 13 2026, 04:04 EDT). This is a cumulative continuation of WIP1–WIP5 and 0.0.9.1D; no physics or animation behavior was changed.

## Source-level issue / reproduction

`runtime_0_0_9_0F/source/sonic_gpu.c` submits every decoded mesh as `GPU_TRIANGLES` and reads position/normal/UV float32 values from SA3C. The loader validated references, textures and ACTIONs but did not check that the mesh's expanded index count is divisible by three, that the retained source primitive class is supported, or that *referenced* vertex float32 components are finite. A malformed owner-generated SA3C could therefore pass earlier validation and send a partial triangle or NaN/Inf coordinate to the GPU. This is a confirmed source-validation gap, **not a claim that original Sonic data is malformed or that an observed hardware glitch has been fixed**.

## Implementation

- `src/sa3c/sa3c_gpu_preflight.c/.h`: added `sa3ds_geometry_preflight()` and detailed error report. For every mesh: check bounds, source Basic primitive class (`0xC000` strips / `0x4000` quads, both expanded by the owner-side builder), triangle-list count, each index, and all eight float32 components (position xyz, normal xyz, raw UV xy) for every referenced vertex. Empty meshes are allowed, as the existing renderer skips them. Checks are read-only and O(total referenced indices). No arbitrary UV clamp is imposed; UV wrap semantics remain source-backed partial.
- `runtime_0_0_9_0F/source/main.c`: reject invalid geometry before Citro3D initialization, print failing mesh/index/vertex/component; dev banner updated. The source path uses the already-built native `sa3c_gpu_preflight.c`, so no extra SDK dependency was added.
- `tests/test_sonic_geometry_preflight.c`: synthetic valid triangles, strip/quad classes, NaN UV, Inf normal, bad index, invalid primitive, partial triangle, empty mesh, mesh range, invalid section, null arguments.
- `tests/run_sonic_geometry_preflight.sh`: strict host compile + native loader source integration contract.
- `tests/run_sa3ds_current_host.sh`: cumulative WIP6 test gate appended after inherited suites.
