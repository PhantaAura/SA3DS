# SA3DS development control map — 0.0.8.2

## Shared / Classic commands
- Circle Pad — move / steer
- A — jump family
- B or X — contextual ACTION
- L/R — manual camera rotate
- Y — camera recenter
- START — exit in Movement Lab (pause in eventual game)
- SELECT — dev overlay

## RESTORED shortcuts
- D-Down — request Spin Dash
- D-Up — request Light Speed action
- D-Left — snap camera 45 degrees left
- D-Right — snap camera 45 degrees right

The D-pad ability shortcuts **request the same eventual SA1 action states**.
They are not permission to skip eligibility, charge, targeting, collision, or
physics rules. Until those rules are verified, the portable physics core
records these requests but does not invent behavior for them.
