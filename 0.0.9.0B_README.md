# SA3DS 0.0.9.0B
## Physics-Synced Animation Gate

The goal of this checkpoint is not to invent Sonic animations. It guarantees that when the real source motions arrive, they are selected from the actual gameplay state and stay synchronized to the frozen 60 Hz physics simulation.

### Runtime order

```text
input
  -> frozen SA1 physics tick
  -> completed SA1PlayerState
  -> Sonic animation intent observer
  -> future real ACTION/MOTION resolver
  -> animation sampler
  -> renderer
```

There is no arrow back from animation into physics.

**1 P, no Rs — PORT. No remake. No remaster. Just a port with QoL.**

Normal SA3DS remains source-faithful by default. Curated mods remain explicit optional layers.
