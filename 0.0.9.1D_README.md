# SA3DS 0.0.9.1D — CAM Bank Decode / Source Preservation

**True cumulative successor of 0.0.9.1C.** This is an owner-side *data importer*, not an implemented SA1 camera controller or new 3DS executable.

## Verified source findings (owner's 2004-style SADX system archives)

- 127 recognizable `CAM*.BIN` sources; **4,955 original 64-byte rows** in aggregate.
- Header = **64 bytes**: little-endian u32 count and 60 reserved zero bytes. Payload = `count * 64` exact bytes, all 127 files conform.
- Two original files have **zero records**: `CAMMI0402S.BIN` and `CAMMI0102B.BIN`. Zero is valid.
- The first 8 bytes of a row can be read as `u16, u16, u32`; their semantic roles remain **unverified**. The other 56 bytes are preserved **bit-for-bit as opaque payload**. Do not assume position, scale, camera eye/target, priority, trigger, or FOV merely from float-looking values.
- At `CAM0701S.BIN` row 169, row offset `+32` holds `0xFFD00000`, a NaN if interpreted as f32. This is in the owner's apparently valid stock source. **Do not reject or canonicalize it.**
- Both owner `system.zip` and `system 2.zip` contain the **same 127 CAM files, 127/127 SHA-256 identical**.
- Emerald Coast uses five recognized CAM banks: `CAM0100S/E`, `CAM0101S`, `CAM0102S/B`; they contain **189, 133, 4** records by act, respectively (326 total). File suffix behavior and selection are not yet proven.

## New code

- `tools/importers/pc2004_cam.py`: strict format reader; lossless source round-trip; neutral pointer-free `SA3DCAM` (v1) chunk with SHA-256 provenance, CRC32, contiguous row offsets, validated names, and duplicate-source rejection.
- `tools/build_pc2004_cam_packages.py`: batch imports supported files into owner-only `.sa3dspak` packages with `METADATA + CAMERA`. Numeric `CAMnnnnX` groups by level/act from filename; other names remain independent sources. Named file grouping does *not* assign meaning to hub/mission/minigame scripts.
- `tools/build_pc2004_emerald_coast_visual.py --with-cam`: embeds a validated `CAMERA` chunk in each EC visual package, independently of `--with-set`. With both enabled each owner-only act package holds `METADATA, GEOMETRY, MATERIALS, TEXTURES, SET, CAMERA`.
- `tests/test_pc2004_cam.py`: corruption/round-trip/sentinel/zero-count/duplicate tests, all 127 owner sources, 3-act integration, and full batch import.

## Owner-side commands (don't distribute generated Sega-derived packages)

```bash
python3 tools/build_pc2004_cam_packages.py \
  '/path/to/system 2.zip' /tmp/sa3ds_cameras --report /tmp/cameras.json

python3 tools/build_pc2004_emerald_coast_visual.py \
  '/path/to/sonic.exe' '/path/to/system 2.zip' /tmp/sa3ds_ec \
  --with-set --with-cam --report /tmp/sa3ds_ec_report.json
```
